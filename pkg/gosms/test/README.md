# gosms 测试目录

本目录包含腾讯云SMS的真实发送测试程序。

## 📁 文件说明

- `.env` - 配置文件（包含敏感信息，不要提交到版本控制）
- `env_loader.go` - 环境变量加载器
- `send_and_query.go` - 短信发送和状态查询测试程序

## 🔧 配置步骤

### 1. 编辑 .env 文件

修改 `.env` 文件中的配置项：

```bash
# 腾讯云SMS配置
TENCENT_SECRET_ID=你的SecretID
TENCENT_SECRET_KEY=你的SecretKey
TENCENT_SMS_APP_ID=你的AppID

# 短信配置
SMS_SIGN_NAME=你的短信签名
SMS_TEMPLATE_ID=你的模板ID

# 测试手机号（请修改为实际要发送的手机号）
TEST_PHONE_NUMBER=+8613711112222
```

### 2. 前置条件

使用腾讯云SMS前必须完成：

1. ✅ 在腾讯云控制台创建短信应用
2. ✅ 申请并审核通过短信签名
3. ✅ 创建并审核通过短信模板
4. ✅ 获取正确的 SecretId、SecretKey 和 AppID
5. ✅ 确保账户有足够的短信余额

## 📋 测试流程

测试程序会自动执行以下步骤：

1. **加载配置** - 从 `.env` 文件或环境变量加载配置
2. **创建客户端** - 使用配置创建腾讯云SMS客户端
3. **发送短信** - 生成随机验证码并发送短信
4. **等待处理** - 等待5秒让短信系统处理
5. **查询状态** - 查询短信发送状态
6. **显示结果** - 展示发送和查询的详细结果

## ⚠️ 注意事项

### 安全提醒

1. **不要将 `.env` 文件提交到版本控制系统**
2. **定期更换 API 密钥**
3. **测试完成后及时删除测试数据**

### 费用说明

- 每次测试都会发送真实短信，会产生费用
- 请在测试前确认账户余额
- 建议先使用少量测试

### 常见问题

#### 1. 发送失败：签名或模板未审核

**解决**：在腾讯云SMS控制台确认签名和模板已审核通过

#### 2. 发送失败：手机号格式错误

**解决**：使用国际格式，如 `+8613711112222`

#### 3. 查询不到状态

**解决**：
- 等待更长时间（可能需要几分钟）
- 检查查询时间范围是否正确
- 确认 MessageID 是否正确

#### 4. 余额不足

**解决**：在腾讯云控制台充值
